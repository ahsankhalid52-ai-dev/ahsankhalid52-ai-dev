## My Projects

### 1. Robust Indoor Localisation Under Sensor Noise

This is my MSc research project, where I explored how machine learning can predict indoor locations using Wi-Fi signals.

I used the UJIIndoorLoc dataset and tested KNN and Random Forest models to understand how noise and missing Wi-Fi signals affect prediction accuracy. I also explored filtering techniques to improve the reliability of location predictions.

[View Project](https://github.com/ahsankhalid52-ai-dev/robust-indoor-localisation)

### 2. Fashion-MNIST Image Classification

In this project, I worked with the Fashion-MNIST dataset to classify different types of clothing images.

I developed neural network models using PyTorch, including an Artificial Neural Network (ANN) and a Convolutional Neural Network (CNN), and compared their performance.

[View Project](https://github.com/ahsankhalid52-ai-dev/fashion-mnist-image-classification)

### 3. NLP Chatbot

For this project, I explored how deep learning can be used to build a chatbot that processes text and generates responses.

I worked with natural language processing techniques, including text preprocessing, sequence-to-sequence learning and attention mechanisms.

[View Project](https://github.com/ahsankhalid52-ai-dev/nlp-chatbot)
